第一步：填入 OpenAI API Key

  1. 打开 platform.openai.com/api-keys，登录后点 Create new secret key，复制那串以 sk- 开头的字符。
  2. 在 Billing 充值（5–10 美元能用很多节课），并建议在 Limits 设一个每月上限。
  3. 粘贴到下面，点「保存并测试」。
Key 只保存在这台设备的浏览器里，只会发送给 OpenAI，不会经过任何别的服务器。
